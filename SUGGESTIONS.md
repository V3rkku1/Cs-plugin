## Features

- [x] Workshop map list with a saved game mode per map (movement hub always starts in Custom, surf in Custom, etc.)
- [x] Round-type announcer in retakes: big "ECO / FORCE / FULL" banner at round start
- [x] Eco/force rounds also limit bots to the same buy type
- [x] Keep each player's last buy per round type (eco pistol, force SMG, full rifle) and give it back next time
- [x] Sticker preview per weapon type (real slot positions for AK, M4, AWP...) instead of one shared guide
- [x] Sell/trade-up in bulk from the Inventory (select many, sell all duplicates)
- [x] Inventory filters: StatTrak only, by case, by price range
- [x] Favorite items pinned to the top of the Inventory
- [x] Per-map team size presets (e.g. 2v2 on small workshop maps, 5v5 on Dust2)
